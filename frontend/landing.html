Namma Route

Event-Driven Congestion Forecasting

An enterprise-grade Decision Support System custom-built for the Bengaluru Traffic Police. It uses computer vision and machine learning to instantly forecast the impact of traffic anomalies and recommend surgical resource deployments before gridlock cascades across the city.

Launch Command Center

The Four Core Pillars

Automated CCTV Watchtower

Autonomous YOLOv8 computer vision engine that monitors live junction feeds to detect accidents and breakdowns, bypassing slow manual reporting.

Impact Forecasting Engine

XGBoost and KNN machine learning models instantly predict the severity and exact clearance duration of an event before gridlock cascades.

Resource Recommendation

A deterministic heuristic planner that tells dispatchers exactly what resources to deploy (e.g. Heavy Tow Trucks) and calculates optimal diversions.

Continuous Learning Loop

An automated feedback mechanism where ground officers log actual clearance times, allowing the system to continuously retrain and adapt to the city.

Astram Data Platform

  • Source: Anonymized Bengaluru traffic-event logs from the official Astram platform.
  • Scale: Over 8,200 meticulously cleaned historical events spanning 6 months.
  • Engineering: Features include hour-of-day, spatial clustering, and log-transformed durations.
